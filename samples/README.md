# Long-form Tagalog stress-test story

`tagalog_tts_anthology.txt` is the original generated Tagalog anthology from the early VisualBook conversation. It is an **example input**, not proof of a production story app. It contains multiple short/long Juan/Pedro-style narratives for parser segmentation, subtitle, chapter-navigation and TTS gap evaluation.

- UTF-8 plain text and ordinary narration by default.
- No character markup is interpreted unless explicitly converted to a structured script.
- Previous research reported 1,765 narration blocks and 4,035 suggested speech chunks with a limited heuristic compiler; those figures are historical test observations, not a promise of natural speech quality.
- File source SHA-256 (original local): `858860b156b2f76781199f9a5170f3b1dba8c1f59acb8b2bae27665b47833c14`.

Do not ship these test stories inside an app unless product packaging choices justify their inclusion.
