# Juan at Pedro — Mga Kuwento ng Bayan ng Maligaya

**Status:** Original continuous Filipino serial. Season 1 planned for eight connected episodes, beginning with Episode 1 `Ang Kampanang Nawala` (~24-minute script target; phone TTS duration unverified).

The tone draws on distinct historical Juan/Pedro variants and Juan Tamad/púsong trickster tradition, but the town, mystery, relationships, and cast roles are **new original fiction**, not a single verified folkloric canon.

## Compatibility notes

The script uses v0.6-supported directives only: `@bg neutral`, `@n`, `@c1m` through `@c9m`, `@chibi` and `@end`. The actual renderer currently supports generic stages and speakers—not all desired specific backgrounds, gestures, sounds or cast persistence described in the production guide. No voice track or polished movie is included. Import the `.story.md` as *script*, not plain TXT, in the Android player.

The first episode compiles into approximately 430 Java BreakIterator speech segments, under the prototype limit of 500. Runtime must be timed on the intended offline TTS voice.

## Continuity rule

Future chapters must continue existing clues: bell damage, partial map and second spring Balete, red half-leaf seal, unknown assistant Elias (voice c9), Esteban's suspected interference, town covenant, and the morning departure. Never silently invent a new unrelated Juan/Pedro premise after E01.
